# 1층 전기요금 나누기

한전 고지서의 실제 전기요금을 1층 세입자와 집주인의 사용량 비율대로 나누는 무료 정적 웹페이지입니다.

## 사용 방법

1. `index.html`을 브라우저로 열거나 배포된 웹주소에 접속합니다.
2. 같은 사용기간의 한전 고지서, **지난달 적어 둔 1층 계량기 숫자**, **이번 달 확인한 1층 계량기 숫자**를 준비하고 **시작하기**를 누릅니다.
3. 한 화면에 한 항목씩 나타납니다. 화면의 **큰 숫자판**으로 값을 넣고 **다음**을 누릅니다. 순서는 전체 사용량 → 지난달 계량기 숫자 → 이번 달 계량기 숫자 → 전기요금입니다. **지우기**는 한 글자를 지우며, **이전으로** 돌아가도 적은 숫자는 남습니다. 일반 키보드 입력도 가능합니다.
4. 금액 입력 전 안내 화면에서 포함·제외 항목을 확인합니다. **기본요금·부가세·전력산업기반기금까지 포함하고 고지서의 할인이 반영된 이번 사용기간의 실제 전기요금**을 넣습니다. **TV 수신료·연체료·지난 미납금 등은 제외**합니다. 마지막 화면의 **계산하기**를 누르고 결과에서 두 사람의 사용량, 비율, 부담액을 확인합니다. 필요하면 **계산 방법 보기**를 펼칩니다.
5. **정산 결과 복사**를 누르고 카카오톡 대화창에 붙여넣습니다. **다시 입력**은 네 값을 모두 지웁니다.

입력칸은 완전히 비어 있고 예시 숫자도 표시하지 않습니다. **지난달 계량기 숫자**는 지난달에 계량기를 보고 기록한 누적 숫자입니다. 지난달 사진이나 기록이 없으면 정확히 정산할 수 없습니다. 지난달~이번 달 확인 날짜는 고지서의 사용기간과 맞아야 합니다.

결과의 **입력한 숫자 고치기**는 기존 숫자를 유지한 채 첫 입력 화면으로 돌아가며, **다시 입력**은 네 값을 모두 지웁니다. 수정 중에는 이전 정산 결과를 숨기며 마지막에 다시 계산해야 합니다.

## 기본요금·세금·할인은 어떻게 처리하나요?

이 페이지는 **한전이 실제로 청구한 금액을 두 사람이 합의한 사용량 비율로 배분하는 도구**입니다. 한전의 가구별 별도 요금 산정기나 공식 계산기는 아닙니다.

한전의 청구 구조는 기본요금 + 전력량요금 + 기후환경요금 + 연료비조정요금에 해당 할인 등을 반영하고, 부가가치세와 전력산업기반기금을 더하는 방식입니다. 따라서 **이 항목들이 모두 포함된 최종 금액을 한 번만 입력**하면 기본요금과 세금도 함께 비례 배분됩니다. 이미 고지된 금액에 기본요금·세금·기금을 다시 더하지 않습니다. 요율이나 누진 구간을 추정할 필요도 없습니다.

- **포함:** 이번 사용기간의 기본요금·전력량요금·기후환경요금·연료비조정요금·부가세·전력산업기반기금. 고지서에 실제 적용된 할인·감면은 반영된 상태의 금액을 사용합니다.
- **제외:** TV 수신료, 연체료·가산금, 지난 미납금, 다른 사용기간의 정산액 등 이번 사용기간의 전기요금과 별개인 금액. 고지서에 적힌 실제 금액을 확인해 빼며, TV 수신료 등을 고정 금액으로 가정하지 않습니다.
- **주의:** ‘전기요금계’는 세금과 기금을 더하기 전 소계일 수 있습니다. 반대로 ‘총 청구금액’에는 TV 수신료나 미납금이 섞일 수 있습니다. 항목을 확인한 뒤 정산할 실제 전기요금만 입력합니다. 페이지는 고지서를 읽거나 포함·제외 항목을 자동 판별하지 않습니다.

공식 확인 자료(2026-09-25): [한전ON 전기요금 구조](https://online.kepco.co.kr/PRM005D00), [한전ON 전기요금계산기](https://online.kepco.co.kr/PRM033D00). 변경될 수 있는 요율은 이 페이지에 고정하지 않습니다.

## 정산 전에 맞춰야 할 점

- **같은 기간:** 고지서 발행 월만 맞추는 것이 아니라, 고지서의 ‘사용기간’ 시작·끝과 두 번의 계량기 확인 날짜가 맞아야 합니다. ‘지난달/이번 달’은 이를 쉽게 부르는 표현입니다. 지난달의 누적 계량기 숫자가 있어야 이번 달 증가분을 알 수 있습니다.
- **같은 단위:** 보조계량기는 숫자 차이가 그대로 kWh가 되는 것을 전제로 합니다. 별도 계기배율을 곱해야 하는 계량기는 현재 네 입력만으로 직접 처리할 수 없습니다.
- **공용 전기:** 전체 사용량에서 1층 사용량을 뺀 나머지를 집주인 몫으로 처리합니다. 따라서 1층 계량기에 잡히지 않은 계단·마당 등의 공용 전기도 집주인 몫에 포함됩니다. 다른 분담을 원하면 별도 합의가 필요합니다.
- **할인 분담:** 고지서에 적용된 할인 효과도 사용량 비율대로 함께 나뉩니다. 특정 사람의 복지할인을 그 사람에게만 귀속시키는 계산은 하지 않습니다.
- **범위:** 다른 세입자의 별도 분담, 계량기 교체·초기화·자리수 순환, 음수 환급금, 태양광 상계 등 별도 정산이 필요한 상황은 이 단순 비례식만으로 판단하지 않습니다. 전체 사용량이 0이면 비율을 만들 수 없어 계산을 막습니다.

## 계산 방식

- 1층 사용량 = 이번 검침값 − 지난번 검침값
- 1층 사용 비율 = 1층 사용량 ÷ 집 전체 사용량
- 1층 부담액 = 실제 전기요금 × 1층 사용 비율, 원 단위 반올림
- 집주인 사용량 = 전체 사용량 − 1층 사용량
- 집주인 부담액 = 실제 전기요금 − 1층 부담액

예: `600 / 1000 / 1450 / 120000` → 1층 **450 kWh·75%·90,000원**, 집주인 **150 kWh·25%·30,000원**. 합계 **120,000원**.

한전 요율이나 누진 구간은 계산하지 않습니다. 금액은 반올림 전의 정확한 사용량 비율로 계산하고, 화면의 비율은 최대 소수점 둘째 자리로 표시합니다. 소수점 사용량은 최대 6자리, 정수부는 최대 12자리까지 지원하며 요금은 정수 원 단위만 받습니다. 1,000처럼 올바르게 묶은 쉼표도 허용합니다. BigInt 정수 연산으로 소수점 오차 없이 반올림합니다.

전체 사용량 0, 지침 역전, 1층 사용량 초과, 빈칸, 음수, 문자 등은 계산하지 않습니다. 두 검침값이 같거나 실제 요금이 0원인 경우는 정상 처리합니다. 계량기 교체·초기화·자리수 순환으로 이번 지침이 작아진 경우에는 이 차감 방식으로 정산할 수 없습니다.

## 실행 및 개인정보

`index.html` 한 파일에 HTML/CSS/JavaScript와 아이콘이 모두 포함되어 있습니다. 설치, 빌드, 서버, 외부 폰트, CDN, 외부 라이브러리가 필요 없습니다. 인터넷 없이 파일을 직접 열어 계산할 수 있습니다. BigInt를 지원하는 현대 브라우저를 사용합니다.

개인정보 입력란이 없고 입력값을 저장하거나 네트워크로 전송하지 않습니다. 쿠키·브라우저 저장소·통계 수집을 사용하지 않으며 CSP로 네트워크 연결과 폼 전송도 차단합니다. 사용자가 복사 버튼을 누를 때만 정산 문구를 기기의 클립보드에 씁니다. 호스팅 서비스를 통해 접속할 때 발생하는 통상적인 웹페이지 요청은 별개이며 입력 숫자는 포함되지 않습니다.

일부 브라우저에서 자동 복사가 차단되면 결과 문구가 화면에 표시됩니다. 해당 문구를 길게 눌러 선택하여 복사할 수 있습니다.

## GitHub Pages에 직접 올리는 순서

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 선택합니다.
2. 기존 저장소와 겹치지 않는 새 이름을 입력하고 **Public**을 선택한 뒤 저장소를 만듭니다.
3. 새 저장소에서 **uploading an existing file** 또는 **Add file → Upload files**를 선택합니다.
4. 이 폴더의 `index.html`을 올립니다. `index.html`이 하위 폴더가 아닌 저장소 맨 위에 있어야 합니다. 선택적으로 `README.md`와 `.nojekyll`도 올립니다.
5. **Commit changes**로 저장합니다.
6. **Settings → Pages → Build and deployment**로 들어갑니다.
7. **Source → Deploy from a branch**를 고릅니다.
8. 파일을 올린 브랜치(직접 만든 저장소에서는 보통 `main`), 폴더 **/(root)**를 선택하고 **Save**를 누릅니다.
9. 배포가 끝나면 같은 페이지의 **Visit site**를 누릅니다. 주소는 `https://계정이름.github.io/저장소이름/` 형태입니다.
10. 주소를 휴대전화에서 열고 위 예시 값으로 확인합니다. 이후 수정한 `index.html`을 같은 브랜치에 저장하면 다시 배포됩니다.

공식 안내: [GitHub Pages 사이트 만들기](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [배포 브랜치 설정](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).
